# Code Club

> Learning to build AI together • one code review at a time • Humans in the loop.

Welcome! This is a sample repository used for **Code Club** demonstrations. If you're new here, this README introduces what Code Club is, why it exists, and how it works.

![Code Club Logo](media/code_club_logo.PNG)

## What is Code Club?

Code Club is a community-driven, hands-on learning program within the AI & ML community that blends a **virtual hackathon** with a **collaborative code review experience**. Think of it as *a book club for code reviews*: instead of reading a book together, participants work through a shared code repository, build solutions, and then come together to discuss different approaches and the tradeoffs behind them.

**Format:**
- Quarterly virtual sessions
- ~3 hours of hands-on hacking
- Followed by a collaborative code review session
- Ongoing engagement through Viva Engage discussions between events

## Why Code Club Exists

Code Club creates a social and technical learning environment where people learn *from one another* through practical coding — not lecture-based training. It exists to provide:

- Social engagement and peer learning & mentorship
- Diverse technical perspectives and customer empathy
- Opportunities to compare solution approaches and tradeoffs
- Contributions back to open-source communities ("Fork it Forward" — don't just consume open source, give back to it)

## Who Is It For?

Engineers, architects, pro-code developers, and AI/ML practitioners who want hands-on experience building AI solutions. The program is built for people who want to actively code rather than passively observe:

> Open to anyone who plans to code. No spectators.

## Mission & Vision

**Vision**
- Foster a community passionate about advancing AI and machine learning across the organization
- Break through silos and work together as one team
- Network, exchange ideas, learn new things, and share expertise through social learning
- Cultivate best practices and solve difficult problems together

**Mission**
- Build connections across the machine learning community
- Share lessons learned, techniques, tools, and deployed solutions
- Encourage discussion of challenging problems and differing viewpoints

## Goals

1. **Hands-on AI readiness** — improve practical coding skills through real-world AI repositories and labs.
2. **Peer learning** — learn alternative implementation approaches and understand engineering tradeoffs through code reviews.
3. **Community building** — form friendships, support systems, and stronger networks across teams.
4. **Knowledge sharing** — share techniques, lessons learned, and best practices across the AI & ML community.
5. **Open-source contribution** — learn from and contribute back to open-source projects.
6. **Ongoing engagement** — keep discussions, troubleshooting, and learning going through Viva Engage between events.
